# Minimal README expansion

## Quick start

1. Install Docker and Docker Compose.
2. In repo root run: ./run.sh (or run.ps1 on Windows)
3. Default seeded admin: admin@example.com / Admin@123 (change immediately)

## Notes
- Change SECRET_KEY and other secrets in environment for production.
- Notebooks contain training & explainability code; use them to run experiments and save artifacts into /artifacts.
